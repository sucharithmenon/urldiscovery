# Patterns

Pattern modules detect ATS providers and careers-related signals.

## Files
- `ats_patterns.py`: ATS URL detection, normalization, and domain marker support.
- `registry_patterns.py`: long-tail ATS regex catalog for additional detection.
- `ats_fingerprints.py`: HTML fingerprint detection for ATS hints.
- `careers_indicators.py`: URL path and text heuristics for careers pages.
- `__init__.py`: package marker.
